이음 개인정보처리방침

시행일: 2026년 11월 17일

이음은 사용자가 선택한 여러 장의 사진을 이어붙이고 편집하여 하나의 이미지로 저장하는 Chrome 확장 프로그램입니다. 본 방침은 이음의 데이터 처리 방식을 설명합니다.

1. 사진 처리

사용자가 직접 선택한 사진은 사용자의 브라우저 내에서 편집됩니다. 이음은 사진 파일이나 사진의 내용을 개발자 서버 또는 제3자 서버로 업로드하거나 전송하지 않습니다. 사진은 편집 작업을 위해 브라우저의 실행 중 메모리에서 처리되며, 결과 파일은 사용자가 지정한 방식으로 자신의 기기에 저장합니다.

2. 로컬 저장 정보

이음은 작업 편의를 위해 배치 방향, 비율, 간격, 파일 형식 및 출력 크기 등 편집 설정을 확장 프로그램의 브라우저 로컬 저장소(localStorage)에 보관할 수 있습니다. 사진 원본이나 편집 결과물을 해당 로컬 저장소에 저장하지 않습니다.

3. 개인정보 수집 및 외부 전송

이음은 이름, 이메일 주소, 연락처, 위치, 방문 기록 및 이용 행동을 수집하거나 개발자에게 전송하지 않습니다. 광고 추적 도구나 외부 분석 서비스를 사용하지 않습니다. 확장 프로그램은 사용자가 방문하는 웹페이지의 내용에 접근하기 위한 권한을 요청하지 않습니다.

4. 제3자 제공 및 목적 외 이용

이음은 사용자 데이터를 제3자에게 판매하거나 제공하지 않으며, 사진 이어붙이기 및 편집 기능과 무관한 목적으로 사용하지 않습니다. 신용도 판단이나 대출 관련 목적으로 데이터를 사용하지 않습니다.

5. 보관 및 삭제

편집을 위해 메모리에 로드한 사진은 작업 탭을 닫거나 작업을 초기화하면 해당 작업에서 더 이상 사용하지 않습니다. 로컬에 보관되는 편집 설정은 브라우저에서 이음의 사이트 데이터 또는 확장 프로그램 데이터를 삭제하여 제거할 수 있습니다. 사용자가 기기에 저장한 결과 파일은 이음이 자동으로 삭제하지 않습니다.

6. 방침 변경

향후 데이터 처리 방식이 변경되는 경우, 변경 내용에 맞춰 이 방침과 Chrome 웹스토어의 개인정보 보호 관행 공개 내용을 갱신합니다.
